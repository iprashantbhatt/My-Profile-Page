### 🚀 What I'm building

Since 2008 I've been writing online — now I build. Currently juggling projects across AI agents, algorithmic trading, and content:

- 🔭 **[NEXUS](https://github.com/iprashantbhatt)** — Multi-agent system (CEO + 4 agents), Claude API-orchestrated, being extended into a trading-intelligence pipeline: Research agent → Verifier → human-approval alerts → conditional auto-execution with hard risk limits.
- 📈 **EdgeFlow** — Smart Money Concepts (SMC)-based trading system, the eventual execution target for NEXUS's trading extension.
- 🤖 **ResearchBot** — Self-hosted autonomous research bot (Grok Bot-inspired architecture) for NSE/BSE market intelligence. Stack: Brave Search API, Playwright, Claude API + NVIDIA Nemotron, SQLite, PM2. Manager/specialist/verifier multi-agent design, evidence-backed reports.
- ₿ **[House of Bitcoin](https://houseofbitcoin.app)** — Live Bitcoin dashboard: BTC price, halving countdown, Fear & Greed index, on-chain metrics, top 100 coins & news.
- 🎙️ **Neural Dialogues** — Faceless Hinglish AI/tech podcast on YouTube, built on a public-domain-text content pipeline.
- 🌐 **[prashantbhatt.net](https://prashantbhatt.net)** — Personal site with a Liquid Glass glassmorphism UI, 5 switchable themes, showcasing PrashantGPT, XPlorer, Swipely & Omniview.
